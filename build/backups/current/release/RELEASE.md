# J-Roc XCore 1.0 Release Candidate

This release candidate contains the integrated J-Roc ecosystem architecture.

Critical runtime systems must still be validated on the target emulator/hardware
before the project is declared production-ready.

Release components:
- XCore
- Userspace
- Desktop
- Apps
- SDK
- Packages
- Frontend
- Backend
- AI interface
- Cloud interface
- Developer tools
- Installer
- Recovery
- Diagnostics
- Rollback
