# JROC AI Foundation - Complete System

## Quick Start

### 1. Clean Build (Scaffold Only)
```bash
bash JROC_CLEAN_BUILD.sh
```

Creates folder structure with 100 version slots.

### 2. Full Build + Run
```bash
bash JROC_BUILD_RUN.sh
```

Scaffolds + copies all modules + boots JROC Master.

### 3. Manual Run
```bash
cd JROC-AI
python main.py
```

Boots JROC Master with all 9 systems connected.
