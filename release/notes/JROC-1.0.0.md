# J-Roc XCore 1.0.0

J-Roc XCore reaches its first integrated release checkpoint.

Included:
- bootable XCore kernel baseline
- complete subsystem architecture
- process/scheduler foundations
- memory/interrupt foundations
- storage/network foundations
- security/service foundations
- userspace and SDK
- desktop/frontend architecture
- backend architecture
- package/AI/cloud interfaces
- developer tooling
- installer/recovery framework
- diagnostics
- release validation

Production gate:
Critical low-level and hardware-dependent subsystems require runtime and
hardware validation before being represented as fully production-ready.
