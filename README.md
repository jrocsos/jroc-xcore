# J-Roc XCore

J-Roc XCore is a from-scratch operating-system project.

Current milestone:
- Bootable 32-bit kernel
- GRUB boot
- VGA console
- PS/2 keyboard input
- Interactive JROC shell
- XCore subsystem architecture

Major ecosystem areas:
- Kernel
- Memory
- Interrupts
- Drivers
- Hardware
- Processes
- Filesystem
- Network
- Security
- Services
- Userspace
- Desktop
- Apps
- SDK
- Packages
- AI
- Cloud
- Developer tools
